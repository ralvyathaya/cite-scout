# The Build Games submission

## Description (≤200 characters)

PromptWatch tracks when Perplexity recommends your brand or competitors, preserving daily answers, citations, and transparent visibility trends for $19/month.

## Replacement

Focused replacement for expensive enterprise GEO/AEO visibility monitoring suites and manual spreadsheet checking.

## Why switch

Self-serve setup, a genuine value-first trial, auditable answers, strict cost controls, and one understandable monthly plan.

## Durable value

One general-AI prompt cannot reconstruct yesterday’s answer, detect a disappearance, calculate a comparable trend, or preserve the sources that influenced weeks of recommendations.

## Public demo

Open `/demo`. OrbitCal is fictional, the data is explicitly illustrative, and the route never calls Perplexity.

## Judging position

- **Best Replacement:** a narrow, affordable alternative to enterprise monitoring.
- **Most Creative:** transparent longitudinal AI observations rather than a generic chat wrapper.
- **Most Polished:** editorial analytics UI, auditable citations, billing integrity, quotas, accessibility, tests, and production operations.

## Limitations

The MVP observes the Perplexity Agent API only. Results are directional and nondeterministic, not exact rankings or replicas of consumer AI applications.
