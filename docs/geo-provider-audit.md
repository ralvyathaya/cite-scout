# GEO provider audit — 2026-10-11

This implementation addendum supersedes the original plan's mandatory Jev/DataForSEO choices. The user requested Clef Flash as primary classifier, an optional Jev adapter, optional DataForSEO, real target responses where available, and an isolated fixture flow without API costs. Product scope, evidence transparency and comparison limits remain in force.

| Original DataForSEO use | Endpoint family                                                                    | Data collected                                                     | MVP treatment                                     |
| ----------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------- |
| Google AIO              | `/v3/serp/google/organic/task_post` and saved `task_get/advanced`                  | Actual Google overview, SERP results and answer/element references | Optional adapter; unavailable when not configured |
| ChatGPT Search          | `/v3/ai_optimization/chat_gpt/llm_scraper/task_post` and saved `task_get/advanced` | Captured ChatGPT search answer and reported model/references       | Optional adapter; unavailable when not configured |
| Bing Copilot Answers    | `/v3/serp/bing/organic/task_post` and saved `task_get/advanced`                    | Copilot overview in Bing, nested references and SERP results       | Optional adapter; unavailable when not configured |

Perplexity continues using its actual Agent API. It is labeled as that API surface rather than consumer chat UI parity. Missing target collectors never silently become web-search observations.

Serper offers Google SERP research; its public example documents organic links/snippets and does not establish a target AI Overview response contract verified for this implementation. It was considered and audited for supporting discovery, and is not wired into this bounded monitoring MVP. Generic organic SERP cannot be relabeled Google AIO or another target AI answer. [Serper](https://serper.dev/) advertises 2,500 free queries as of this audit; actual entitlement/balance is account-dependent and was not inspected.

Tavily search/extract support source discovery and supplied page evidence. Its optional synthesized answer is not an observation of ChatGPT, Google AIO, Bing Copilot or Perplexity. These options were considered and audited, and remain unwired here because no verified target-response contract justified a monitoring adapter. If added later, auxiliary outputs must stay outside visibility rates and target citation-frequency counts. No Serper/Tavily secrets, installed dependencies or implemented adapter are claimed. [Search reference](https://docs.tavily.com/documentation/api-reference/endpoint/search), [Extract reference](https://docs.tavily.com/documentation/api-reference/endpoint/extract).

Classifier contract: `env.AI.run('@cf/cloudflare/clef-flash', {model:'clef-flash',state,questions})`. Clef Flash is the primary classifier; `clef` explicitly selects `@cf/cloudflare/clef`, and `jev-1.13.0` explicitly selects the optional TypeSafe adapter. The current implementation uses independent native Choice/Noul questions, validates response model/question IDs/options/probabilities/usage, and records distinct model/rubric cohorts. Probabilities are model outputs, not measured accuracy. There is no automatic paid fallback. [Clef Flash](https://developers.cloudflare.com/workers-ai/models/clef-flash/), [Clef](https://developers.cloudflare.com/workers-ai/models/clef/), [TypeSafe native contract](https://docs.typesafe.ai/api).

Local Worker tests disable remote bindings and replace inference/network boundaries with explicit synthetic adapters. Local Wrangler has no `AI` binding; production Wrangler declares it. The implemented localhost-only `?fixture=1` workspace carries a persistent synthetic-data banner, keeps separate browser-memory state, intercepts workspace API calls and does not call real providers/inference/billing or write production monitoring tables. Non-localhost fixture requests fail closed. Live adapters remain gated by credentials/binding, positive operator budgets and explicit enabled flags; all secrets are server-side.

The native DataForSEO adapters submit Standard tasks with the frozen neutral prompt/configuration and an item tag, save task IDs, and poll `task_get/advanced` against that saved identity. Google/Bing only use parsed overview answer content as target evidence; organic results remain retrieved sources. ChatGPT Search captures reported answer/model/references from its dedicated endpoint. Missing engines are explicitly unavailable, and fixtures are never presented as real responses. Successful parsing with no overview is distinct from failure or partial data; `40102` NoSearchResults is `partial`, not `no_feature`. Neither errors nor classifier unavailability imply brand absence. A live account capture for each newly enabled surface is still required before claiming production fidelity.

Ambiguous paid submission is `submission_uncertain`; the operator may recover a saved provider task with matching ID/tag or close it without retry. It never triggers automatic re-POST. Provider-auth/balance/rate-limit and async recovery have only local/synthetic evidence here; live account state, charges and quality are unverified. DataForSEO is optional for local/MVP use, and TypeSafe is needed only for selected Jev. See [operations](geo-operations.md) for exact routes, flags and live gates.

Owned page verification is limited to known owned targets, public DNS records, HTTPS, validated redirects, ten seconds and 128 KB. It observes HTTP/meta/header/canonical signals and never proves indexing. Native Workers `fetch` cannot pin the resolved IP; public-address validation is repeated before each fetch/redirect and Workers' public outbound network is relied on at connection time. Keep this boundary on Workers, and do not port it unchanged to a Node server with private-network access. Page checks remain off by default.
