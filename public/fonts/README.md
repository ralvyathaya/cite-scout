# CiteScout typography

Switzer normal and italic are the supplied unmodified variable WOFF2 files (100–900), from [Fontshare](https://www.fontshare.com/fonts/switzer). See `Switzer-LICENSE.txt` from the official Switzer download.

Newsreader normal (400–500, optical size 6–72) is self-hosted from the [Google Fonts CSS API](https://fonts.googleapis.com/css2?family=Newsreader:opsz,wght@6..72,400..500&display=swap), downloaded October 19, 2026. Latin, Latin Extended and Vietnamese subsets retain the API's Unicode ranges. See `Newsreader-LICENSE.txt` from the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/newsreader).

Switzer is the shared UI and body font across public pages and the workspace, including body portals. Newsreader is used for editorial display headings and workspace page titles. No external font requests or CSP changes are required.
